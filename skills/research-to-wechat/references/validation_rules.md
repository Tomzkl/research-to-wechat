# 数据核对规则清单

成文前必须逐条过。脚本 `validate_figures.py` 覆盖可自动化的部分,其余由你人工核对。

## 自动化(脚本会查)

1. **冲突值** — 同名同期指标出现两个不同数值 → FAIL。
2. **增长率重算** — 有本期 + 上期时,重算同比,与报告给的同比对比(偏差 ≥0.5 个百分点标 WARN)。
3. **比率范围** — 毛利率 / 净利率 / ROE / 资产负债率应在 [0,100]% 内。
4. **资产负债表平衡** — 资产 ≈ 负债 + 权益(偏差 >1% 标 FAIL)。

## 人工(脚本查不了,必须你来做)

1. **单位一致** — 万元 vs 亿元有没有混用;别把「归母净利润」当「净利润」。
2. **口径一致** — 「净利润」到底指归母还是含少数股东?同比的基期对不对?
3. **来源权威** — 数字来自年报正文还是管理层指引?后者必须标注。
4. **异常值追问** — 毛利率骤变、现金流与利润背离,要找到原因;找不到就写「原因待查」。

## 处理原则

- 任何 FAIL 或对不上的数字:停下,向用户报告,让用户定,**不许悄悄改**。
- 核对完要在文章里标注数据来源与报告期。
