# 写作风格规范

## 语言

- 中文为主,专业术语可用英文缩写(ROE、EPS、PE),首次出现给中文全称。
- 面向普通投资者,不是投行报告:少用「综上所述」「赋能」「赛道」等空话。

## 数字规范

- 金额用「亿元 / 万元」,保留 1-2 位小数;增长率用「%」,保留 1 位。
- 引用数字必须给出报告期(如「2025Q3」),禁止无出处数字。
- 同比 / 环比分清楚,不要混用。
- 报告未披露的,写「未披露」,不要估计。

## 篇幅与结构

- 800-2000 字为宜;每段 2-4 句;小标题之下不超过 300 字。
- 结论前置;每个论点至少配一个数字支撑。
- **每个数字都要有"业务解读"**:不要只复述「营收增长 X%」,要说清楚它意味着什么(见下方速查表)。

## 财务洞察速查(写解读时必用)

| 信号 | 解读方向 |
| --- | --- |
| 毛利率 >40%(或显著高于同行) | 有定价权 / 护城河;要对比同行业 |
| 经营现金流 / 净利润 < 0.7 | 赚的是"纸面利润",利润没有变成现金 |
| 经营现金流 / 净利润 > 1 | 现金质量好,回款好、预收款多 |
| 应收账款增速 > 营收增速 | 回款变差,可能靠放宽信用冲收入、藏雷 |
| 存货增速 > 营收增速 | 可能滞销、跌价风险 |
| 扣非净利润 ≪ 归母净利润 | 利润靠非经常性损益(卖资产/补贴),不可持续 |
| 商誉 / 净资产 > 30% | 减值风险高 |
| 净利率与毛利率差距大 | 费用率高(销售/管理/财务),要追问哪一项 |

> 用法:文章里每引用一个核心指标,就从这张表找对应的"解读方向",写成一句有判断的话,而不是只报数字。

## 语气

- 克制、客观;少用「暴涨 / 崩盘 / 史诗级」等情绪词。
- 看空和看多都要给理由,风险提示必写(至少一条)。

## 质量标杆

写之前先读 `examples/golden_article.md`,产出应达到它的水准:结论有观点、每个数字有业务解读、风险写具体(渠道库存、估值),而不是复述报表。

## 禁用

- 编造数据、「合理估计」、模糊出处(如「据市场消息」)。
- 外链图片、外链样式(公众号编辑器不认)。
